VK Ограничение доступа

Что удалось по VK

Доступ к деталям ленты по VK напрямую из текущей среды закрыт (HTTP 418). Поэтому для верификации будем опираться на официальный контент-канал и отчётные материалы.

Примечание: по требованию был сделан анализ VK-источника. Технически сервер VK возвращает блокировку по типу 418 без авторизации, поэтому глубинный разбор постов из VK недоступен в этой сессии.
