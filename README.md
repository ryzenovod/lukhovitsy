# Молодёжный парламент Луховиц

Сайт: [ryzenovod.github.io/lukhovitsy](https://ryzenovod.github.io/lukhovitsy/).

Сначала представлены восемь направлений деятельности, затем мероприятия и проекты. Работа с депутатским корпусом и патриотическое воспитание стоят первыми. В режиме презентации 11 слайдов: вступление, направления, восемь примеров работы, контакты.

Кнопка в шапке включает показ. Перелистывание — кнопками, стрелками влево/вправо, Page Up / Page Down или пробелом. Home / End переходят к первому и последнему слайду, Esc возвращает к странице. На небольших экранах содержимое слайда можно прокручивать.

Сайт работает без сборки и внешних JavaScript-библиотек. Текст и навигация доступны при отключённом JavaScript; режим презентации появляется после загрузки скрипта.

## Локальный запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть [localhost:4173](http://127.0.0.1:4173/).

## Публикация

GitHub Pages публикует корень ветки `main`. Работа с репозиторием и публикация выполняются терминальными командами `git` и `gh`.

## PDF

Внизу раздела контактов размещена ссылка «Скачать PDF». Она скачивает готовую презентацию из `output/pdf/lukhovitsy.pdf`. В PDF сохранены порядок разделов, фотографии и кликабельные ссылки на источники. На последнем слайде сайта и PDF — QR-коды сообщества ВКонтакте и Telegram-канала.

После изменения содержания PDF нужно пересоздать:

```sh
python3 scripts/export_pdf.py
```

Для генератора нужны `reportlab`, `pypdf` и `Pillow`. Эти зависимости требуются только при подготовке файла; сам сайт работает без них.

QR-коды хранятся локально в SVG и добавляются в PDF как векторная графика. Для пересоздания SVG: `python3 scripts/export_qr.py`.

Основные файлы: `index.html`, `style.css`, `app.js`, `assets/`. Анализ страниц и происхождение фактов: [SOURCES.md](SOURCES.md).
