# Молодёжный парламент Луховиц

Сайт-самопрезентация: [ryzenovod.github.io/lukhovitsy](https://ryzenovod.github.io/lukhovitsy/).

Восемь направлений работы в порядке, заданном для выступления. Фотографии, локальный шрифт Manrope, адаптивная вёрстка и режим презентации из 10 слайдов: вступление, восемь глав, контакты.

Кнопка в шапке включает показ. Перелистывание — кнопками, стрелками влево/вправо, Page Up / Page Down или пробелом. Home / End переходят к первому и последнему слайду, Esc возвращает к странице. На небольших экранах содержимое слайда можно прокручивать.

Сайт работает без сборки и внешних JavaScript-библиотек. Текст и навигация доступны при отключённом JavaScript; режим презентации появляется после загрузки скрипта.

## Локальный запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть [localhost:4173](http://127.0.0.1:4173/).
